| 23 | 往来对象（辅助核算）维度 | 「人」靠 payee/narration 文本承载（`Assets:Receivables:Lend` 单账户，查不出谁欠谁、还款不知谁还）；每人一子账户方案被否（账户爆炸） | **posting 级 metadata `counterparty` + SQLite 索引列 + 往来账净额报表；核销关系用 `^link`（P2）** | 痛点：「不知道谁欠我多少」「还款时不知道是谁还的」。**方案定稿 + 落地（2026-09-13）**：① Beancount 语法边界实测（v3.2.3）——meta key 必须 ASCII（`counterparty`；中文 key 报 `Invalid token`），值可中文；tag/link **均不允许中文**（`#李志全` / `^李志全` 报 `Invalid token`）；meta 值是**标量**（`settles: "a", "b"` 语法错误），`^link` 是**集合**（`^a ^b` → `links=['a','b']`，可一次挂多个）——故「人」用 metadata、「核销」只能用 link。② `counterparty` 取 **posting 级**而非 transaction 级：报表/索引本就是 posting 级聚合（`GROUP BY counterparty WHERE account LIKE 'Assets:Receivables:%'`），一笔交易同时碰两个往来对象时 transaction 级语义塌陷，代价仅一行缩进。③ 索引层回退：先读 posting meta，缺则回退 transaction meta（手工编辑 / 导入 / 历史数据零迁移）。④ link 挂不到 posting（`^link` 写在 posting 上是语法错误）→ 多对多核销只能挂 transaction 级；约定 link 值带人名前缀（`^lizhiquan-lend-a`）以归因到 posting；ID **不从内容派生**，创建时盖不透明 ASCII 串（`^lend-<nanoid>`），此后改日期/金额不悬空；悬空 link（指向已删借款）Beancount 不报错，由索引重建时自校验 warning。⑤ payee 还原为流水原文，「人」交给 counterparty（当前 `微信转账-李志全` 是把人硬编码进 payee 的权宜）。⑥ 往来类判定：`accounts.json` 账户加 `counterparty: true` 标志（`借出` / `还款` 两条），UI 与校验读标志、不硬编码账户名。⑦ 金额累计走 `decimal.ts`，SQL 只做筛选（铁律 5）。**P1** = counterparty 落索引列 + 往来账报表（净额即未结余额，解决痛点）；**P2** = `^link` 核销（FIFO 自动匹配最早未结笔，UI 仅加「结清哪几笔」一个交互）——P2 为叠加富化非地基，无它净额报表仍成立，故后置。**落地实况（2026-09-13）**：P1 = 引擎提取 counterparty（posting 级优先、transaction 级回退）→ `postings.counterparty` 列（索引 schema **v2**，`PRAGMA user_version` 版本闸门——`CREATE TABLE IF NOT EXISTS` 补不了已存在表的列）+ `report:counterparty-ledger` 通道（账户库标志圈定往来类账户，不硬编码账户名）+ 科目管理「往来」开关 + 录入页「往来对象」输入（`ledger:list-counterparties` 历史候选补全，防手误分裂对象）+ 一次性回填脚本 `scripts/backfill-counterparty.mjs`（dry-run 默认、文本级插入、引擎校验后原子替换、幂等）。P2 = 索引 schema **v3** 新增 `entry_links` 表；**link 由主进程在 add-entry 时自动盖/挂**（`withAutoLinks`）——一处覆盖手工录入 / Excel 导入 / AI 草稿全部写入路径，调用方无需知情；新借出盖 `lend-<base36 时间><10 位随机>`，还款按 **FIFO 挂该对象最早的未结贷款**；「借出明细」表按 link 聚合出逐笔的借出 / 已还 / 未结 / 状态。**与原方案的两处偏差**：ⓐ「UI 选笔」未做——自动 FIFO 服务端分页）：展开是少数行才触发的动作，故独立成通道而非塞进汇总载荷（打开报表不背全量流水的传输）；累计余额按**全量升序**算出后再切片，分页只切输出不切累计起点，故每页「余额」都与主表「净额」勾稽（最新一笔 === 净额）。**另修一个静默 bug**：beancount 字符串用 C 风格转义（实测 `"a\b"` 解析为退格符），原 `quote()` 只转义引号不转义反斜杠，payee 含 `\` 时会被静默写坏 |
